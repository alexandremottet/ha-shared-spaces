# Espace Partagé — Shared Studio

Cet utilitaire a été fait pour rendre l'utilisation de Home Assistant dans un contexte d'espace partagé simple d'utilisation.
Le besoin initial venait de l'utilisation qu'on avait de Home Assistant dans l'espace partagé où je travaille Le Portemine (https://www.leportemine.fr).

Afin d'être clair : il s'agit d'un outil pensé et développé avec un avis très orienté (décrit plus bas), avec un parti pris fort sur comment plusieurs personnes partageant un espace peuvent se servir de Home Assistant globalement pour le chauffage. Il ne correspondra peut-être pas à tous les manières de fonctionner de personnes à travers le monde. Si vous pensez qu'une fonctionnalité serait intéressante n'hésitez pas à contribuer.
