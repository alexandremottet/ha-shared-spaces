# Espace Partagé — Shared Studio

Cet utilitaire a été fait pour rendre l'utilisation de Home Assistant dans un contexte d'espace partagé simple d'utilisation.
Le besoin initial venait de l'utilisation qu'on avait de Home Assistant dans l'espace partagé où je travaille Le Portemine (https://www.leportemine.fr).
